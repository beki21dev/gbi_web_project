About This Project

Anchor Tasks was created to demonstrate modern web development practices with a focus on clean design, responsive layout, and intuitive user experience. The application features:

  • Task management with priority levels
  • Advanced filtering and sorting
  • Real-time search functionality
  • Local storage for data persistence
  • Dark/Light theme toggle
  • Responsive design for all devices
